# PPO 학습 설정 파일 사용법

`scripts/ppo.py`의 수치(보상, 패널티, 학습률 등)는 코드를 고치지 않고 JSON 파일로 바꿉니다.

## 1. 준비

```bash
pip install -r requirements-ppo.txt
```

## 2. 실행

`--config`를 주지 않으면 `scripts/ppo_configs/penalty_detail.json`을 읽습니다. 에디터의 실행 버튼도 같습니다.

```bash
python scripts/ppo.py
```

다른 설정 파일로 실행하려면:

```bash
python scripts/ppo.py --config scripts/ppo_configs/내실험.json
```

시작할 때 로그 첫 부분에 읽은 설정 파일, 저장 위치, 보상·패널티 값이 출력됩니다. 값이 의도대로인지 확인하세요.

## 3. 실험하는 방법

1. 자기 브랜치에서 `penalty_detail.json`의 값을 바꿉니다. 한 브랜치에서 실험을 여러 번 하려면 파일을 복사해서 `--config`로 가리키세요(원래 값이 사라지지 않습니다).
2. **`run.output_dir`을 실험마다 새로 정합니다.** 비워 두면 `results/ppo`에 저장되고, 그 폴더에 체크포인트가 있으면 이어서 학습하므로 결과가 섞입니다.
3. 실행합니다. 총 300,000 Step 기준으로 코어 16개에서 약 2.5~3시간입니다(코어 수가 적으면 더 걸립니다). 짧게 확인하려면 `run.total_timesteps`를 줄이세요(예: 10240).
4. 끝나면 출력 폴더에 CSV 4개, 그래프 7장, 학습된 모델(`ppo_policy.pt`, `ppo_best.pt`)이 저장됩니다.
5. **실제로 쓴 수치는 출력 폴더의 `config.json`에 저장됩니다.** 나중에 무슨 값으로 돌렸는지는 이 파일로 확인하세요.

명령줄에서 한 값만 덮어쓸 수도 있습니다(파일은 그대로).

```bash
python scripts/ppo.py --set reward.cost_buy=0.3 --set run.output_dir=\"C:/결과/실험1\"
```

## 4. 파일 안의 구역

값을 바꾸는 곳은 네 구역입니다. 파일에 적지 않은 항목은 코드의 기본값을 씁니다. `_`로 시작하는 키는 설명 메모라서 무시됩니다.

| 구역 | 주요 항목 |
|---|---|
| `run` | 총 Step, 이어 학습 여부, 시드, 출력 폴더 |
| `ppo` | `gamma`(할인율), `lr`(학습률), `gae_lambda`, `clip_eps`, `epochs`, `minibatch_size`, `entropy_coef`, `hidden`(신경망 크기) 등 |
| `eval` | 정기 평가 간격과 판 수 |
| `reward` | 보상과 패널티 전부 |

### 보상·패널티 (`reward`)

값은 학습용 배율 `scale`(0.01)을 곱하기 전 값입니다.

| 구분 | 키 | 의미 |
|---|---|---|
| 보상 | `clear` | 소동을 버틸 때마다 |
| 보상 | `goal` | 30소동 클리어 |
| 보상 | `boss` | 소동 번호별 보스 처치 |
| 패널티 | `life` | 결계 1 잃을 때마다(양수로 적음) |
| 패널티 | `boss_life` | 보스 소동에서 결계 1당 `life`에 더해지는 추가분 |
| 패널티 | `over` | 게임 오버(음수로 적음) |
| 패널티 | `sell_loss` | 판매로 잃는 골드 1당 |
| 패널티 | `cost_sell` | 판매 1번마다 고정 |
| 패널티 | `action_cost` | 소동 시작·소환·강화·판매 모두에 공통 |
| 패널티 | `cost_start` / `cost_buy` / `cost_upgrade` | 해당 행동에만 더해지는 값 |

- 소동 시작에 패널티를 줄 때는 `clear`보다 작게 두세요. 크면 일부러 지는 쪽으로 학습될 수 있습니다.
- 현재 `penalty_detail.json`은 소환·강화·판매에 행동 패널티 0.5, 판매 손실 0.15, 소동 시작은 패널티 없음입니다.

## 5. 주의

- **JSON으로 되는 것은 수치뿐입니다.** "10소동 이후에만 패널티"처럼 새 조건이나 게임 규칙(소환 비용 등), 관측값 구성을 바꾸려면 코드를 고쳐야 합니다.
- 없는 항목을 적으면 바로 오류가 납니다(오타 방지). 오류 메시지에 항목 이름이 나옵니다.
- **브랜치를 합칠 때 `penalty_detail.json`은 건드리지 마세요.** 실험 값이 들어간 파일을 합치면 충돌이 납니다. 합치기 전에 원래 값으로 되돌리거나 이 파일을 빼세요.
- `sell_penalty.json`, `continue_sell_005.json`은 이전 실험을 다시 돌릴 때 쓰는 기록용입니다. 새 실험에는 쓰지 않아도 됩니다.
